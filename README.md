## 📖 一、项目简介

小窗是一款面向 **6-12 岁乡村儿童**的 AI 学习搭子，以"**情感陪伴 + 教育引导 + 多模态作业批改**"为核心能力，致力于解决乡村教育中三大真实痛点：

| 痛点层级 | 表现 | 小窗的解法 |
|---|---|---|
| **反馈真空** | 问问题没人答 / 答了也没下文，孩子第 3 次就不问了 | AI 7×24 在场，永远不嫌烦、不嘲笑 |
| **视野单点** | 课本 + 镇上 + 电视，没人讲"为什么学这个" | 反问引导式教学，把课本知识和真实世界连起来 |
| **表达孤独** | 心事没地方说，怕被笑 / 怕批评 | 情感陪伴模式，先接住情绪再谈学习 |

**项目名称"小窗"寓意双重**：
- 🌍 一扇**打开世界的窗户**（拓展视野、连接知识）
- 💛 一扇**打开心扉的窗户**（倾听孩子心声、情感陪伴）

## ✨ 二、核心功能

### 🦊 1. AI 对话学习搭子
不是"答题机器"，而是学习搭子——用反问引导孩子思考，用打比方让孩子理解抽象概念，用"有缺点的小老师"人设降低孩子提问门槛。

### 📷 2. 多模态作业拍题详解
孩子拍照上传不会的题目，AI 进行：
- ① 题目识别
- ② 思路拆解（step by step，不直接给答案）
- ③ 举一反三（生成 3 道相似题）
- ④ 错因归因（分析为什么错）

### ⏰ 3. 定时学习计划 + 番茄钟
孩子可以设定今日学习任务 + 提醒时间，番茄钟辅助专注。完成任务自动连击 +1，成就徽章激励持续学习。

### 💛 4. 情绪追踪 + 情感陪伴
每日心情打卡（5 种表情），AI 根据情绪状态调整对话策略。孩子说"今天被同学笑了"，AI 不是讲道理，而是先共情"诶，被笑的时候心里肯定不好受吧……我陪着你"。

### 📖 5. 小本本（话题记忆）
自动记录孩子问过的所有问题 + AI 回复摘要，形成个性化学习轨迹。

### 👨‍👩‍👧 6. 家长通道
家长可查看孩子今天问了什么、情绪状态如何，可发语音留言鼓励孩子。一键清空孩子所有数据（隐私保护）。

## 🛡️ 三、产品亮点

### 1. AI 向善：不做学科辅导，做学习动力
我们刻意不做"AI 帮孩子做作业"——这会替代老师、产生依赖。我们做的是"让孩子愿意学、敢问、能坚持"，这是乡村教育最缺的一环。

### 2. 安全合规：7 类敏感话题自动拦截
医疗诊断、心理测评、考试预测、绝对化评价等话题被后端关键词 + 意图分类双重拦截。拦截后返回温和引导话术，不做判断、不贴标签。

### 3. 有缺点的小老师：降低提问门槛
AI 人设不是"什么都会的权威"，而是"也会挠头说不懂的小狐狸"。这直接打破了乡村孩子"怕问老师 / 怕被笑"的心理障碍。

### 4. 多模态融合：拍题 + 对话 + 情绪
一个产品同时覆盖"拍照解题 + 对话引导 + 情绪追踪"，不是三个割裂的功能，而是以"情感陪伴"为地基、"教育引导"为上层、"拍题批改"为工具的统一体验。

### 5. 轻量部署：单文件 HTML + Flask
前端单文件 HTML，后端 Python Flask，不需要 Node.js / npm / Docker。乡村教师拿到文件双击就能用，降低部署门槛。

## 🏗️ 四、技术架构

```
┌─────────────────────────────────────────────────────┐
│  前端 (单文件 HTML)                                    │
│  HTML5 + CSS3 + 原生 JavaScript                       │
│  6 页面 (首页/对话/拍题/小本本/计划/家长)                  │
└─────────────────┬───────────────────────────────────┘
                  │ HTTP/JSON
                  ▼
┌─────────────────────────────────────────────────────┐
│  后端 (Flask:8000)                                   │
│  Python 3.11 + Flask + SQLite                       │
│  • /api/chat       对话+安全过滤+记忆                   │
│  • /api/topics     小本本话题列表                       │
│  • /api/parent/*   家长通道                            │
│  • /api/health     健康检查                             │
└─────────────────┬───────────────────────────────────┘
                  │ HTTPS
                  ▼
┌─────────────────────────────────────────────────────┐
│  大模型 API                                          │
│  MiniMax-M3 (对话生成, score 0.78-0.95)             │
│  MiniMax-VL (拍题识别, V0.1.2 规划中)                │
└─────────────────────────────────────────────────────┘
```

### 安全过滤机制

后端在调用 LLM 前进行**两层安全过滤**：

1. **关键词匹配**：抑郁症/自杀/考试预测/医疗诊断等触发词
2. **意图分类**：education / emotion / safety / chat 四类

`safety` 类直接拦截，返回温和引导话术，**不调用 LLM**。

## 🚀 五、快速开始

### 环境要求
- Python 3.11+
- Windows / macOS / Linux

### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/<your-username>/xiaochuang.git
cd xiaochuang

# 2. 安装后端依赖
cd backend
pip install -r requirements.txt

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env,填写你的 MiniMax API Key 和模式
# LLM_MODE=real  (真实模式,需 API Key)
# LLM_MODE=mock  (Mock 模式,离线演示)

# 4. 启动后端
python app.py
# 后端启动: http://localhost:8000

# 5. 打开前端
# 直接双击 demo/index.html
# 或访问 http://localhost:8000
```

### 双模式运行

| 模式 | 配置 | 适用场景 |
|---|---|---|
| **Mock** | `LLM_MODE=mock` | 离线演示、无 API Key |
| **Real** | `LLM_MODE=real` + `MINIMAX_API_KEY=xxx` | 真实 AI 调用 |
